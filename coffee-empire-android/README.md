# ☕ コーヒー帝国 (Coffee Empire) — Android版 v4.0

Coffee Inc 2 にインスパイアされた、オリジナルのコーヒーチェーン経営シミュレーションゲームの Android アプリです。
(名称・アセット・コードはすべてオリジナルです)

**目標:業界時価総額ランキング1位を30日連続で維持すること。**

## 📲 インストール

`dist/CoffeeEmpire-debug.apk` を Android 端末 (Android 5.0 / API 21 以上) に転送してタップするだけです。

- デバッグ署名のため、インストール時に「提供元不明のアプリ」の許可が必要です
- インターネット権限なし・完全オフラインで動作します
- セーブデータは端末内 (WebView の localStorage) に自動保存されます
- v3 は仕様が大きく変わったため、v1/v2 のセーブデータとは別枠で新規に開始します

## 🎮 設計の中核:成長にブレーキをかける

v2 までは「借金して全商品を開発し、一番良い立地に店を出し続ける」だけで必ず勝ててしまいました
(検証では駅前に1,053店が並び、時価総額1,538億円・一度も危機なし)。v3 では成長が一方通行に
ならないよう、4つの構造的な制約を入れています。

| 制約 | 内容 |
|---|---|
| **商圏は有限** | 各地区の1日の来客数は決まっており、**自店同士でも客を奪い合います**。同じ地区の2店目は1店目の売上を食います |
| **出店枠が有限** | 地区ごとに物件枠(全25枠)があり、競合が埋めた枠には出店できません。枠を超えて拡大する唯一の道が M&A です |
| **管理限界** | 店舗が増えると管理負荷が管理能力を超え、**全店舗の集客と満足度が落ちます**。店長の配属と幹部の就任が必須 |
| **資金と災厄** | 借入枠は直近の業績に連動して伸び縮みし、超過すると資産を強制売却されます。保健所の営業停止・SNS炎上・豆の不作・引き抜き・最低賃金改定が容赦なく襲います |

検証結果:同じ「借金して量産」戦略は**5〜6店舗で頭打ち(管理ペナルティ29%・時価総額0.6億)**となり、
組織を作りながら拡大する良プレイは**約1.7年で1位を達成(157億)**しました。

## 🏛️ 組織と委任(自動化)

規模が大きくなると手動運営は破綻します。**人を採用して任せる**のがこのゲームの本筋です。

- **店長**:各店に配属すると管理負荷が 1.15 → 0.3 に下がり、集客・提供能力・満足度も向上
- **人材市場**:スキルと特性(接客の達人/コスト管理/育成上手/集客の鬼/堅実)を持つ候補者が日々入れ替わる
- **6つの幹部ポスト**:就任させると、その領域を**委任(自動化)**できます

| 幹部 | 委任される仕事 |
|---|---|
| 🧑‍💼 運営本部長 | 管理能力を大幅に拡張＋全店の人員を需要に合わせて自動調整 |
| 📚 人事部長 | スキルの低い店を自動で研修し、離職を抑える |
| 📣 マーケ本部長 | 認知度が下がると予算を見て自動でキャンペーン |
| 🔬 商品開発部長 | 飽きられた商品を外し、新商品を自動開発 |
| 🌱 購買本部長 | 豆相場が安いうちに長期契約を結んでヘッジ |
| 🛡️ 財務本部長 | 敵対的な買い集めを察知して自動で自社株買い |

## 📊 店舗ごとの成績

各店舗に日次の売上・利益・来客・商圏シェア・満足度・士気を表示し、14日分の利益推移をスパークラインで
確認できます。「赤字継続」「行列で機会損失」「店長不在」「士気低下」などの警告バッジと、
ホーム画面の**店舗成績ランキング**で問題店をすぐ特定できます。人員は「推奨人数」表示と
ワンタップの**人員最適化**ボタンで調整できます。

## 🤝 M&Aと株式のドラマ

| 要素 | 内容 |
|---|---|
| 段階的な買い集め | 競合株を5%ずつ取得。買うほど株価が上がる。**33%で拒否権**(相手の行動が鈍る)、**50%で経営権**(全店舗・人材・ブランドを吸収) |
| 相手の防衛 | 新株発行による**希薄化**、他社が助けに入る**ホワイトナイト** |
| 株式交換 | 大型買収は現金では不可能。**新株を発行して買う**と自分の持株が薄まり、今度は自分が狙われる |
| 独占禁止法 | 店舗シェア50%超で当局の監視下に。68%超で課徴金と**分割命令** |
| 逆買収 | 持株50%未満で業績が傾くと🐻投資ファンドと🌟ステラコーヒーが買い進め、**50%取られたらゲームオーバー** |

競合4社はそれぞれ性格を持ち、あなたに**反応します**。ステラコーヒーはあなたの主力地区に殴り込み、
ドリップ&ゴーは価格戦争を仕掛け、珈琲豆善は店長を引き抜き、ねこまど珈琲はSNSで認知度を奪います。

## ☕ その他の要素

- **商品**:13種。品目は7品前後が最適で、増やしすぎるとオペレーションが複雑化して提供が遅れ廃棄も増える
- **鮮度とトレンド**:出し続けた商品は飽きられ、ランダムに特定商品のブームが起きる
- **豆の相場**:日々変動するスポット価格と90日の長期契約。不作で暴騰。自家焙煎工場で変動を半減
- **多角化**:ベーカリー(フード原価-20%)・焙煎工場(豆原価-25%)・コンビニFC・ホテル事業
- **不動産**:投資物件の売買に加え、**店舗の物件を買い取って家賃をゼロに**できる
- **社長**:役員報酬の設定、腕時計からプライベートアイランドまで7種のコレクション(認知度ボーナス)
- **マイルストーン17種**、天気・曜日・季節性、賃金水準と士気・離職


## 🎨 v4.0 の追加要素

### 画面がビジュアルに
- **店舗の外観をSVGで描画**:業態ごとに変わるオーニング、スタッフの人数分の人影、
  行列の長さ、繁盛時の湯気、営業停止中のCLOSED看板まで一目で分かります
- **街のマップ**:地区ごとに客層構成のドーナツグラフ、出店枠のピップ(☕自店 / 🏪競合 / ＋空き)
- **リングゲージ**(評判・認知度・管理負荷)と**時価総額の横バーランキング**

### 👥 顧客セグメントと店舗コンセプト
5つの客層(🎓学生 / 💼ビジネス / 👨‍👩‍👧ファミリー / 👴シニア / ✨感度層)がいて、
**価格感度も好きな商品も違います**。地区ごとに客層構成が異なるため、
「大学前は価格に厳しい学生が65%」「オフィス街はビジネス客が70%で単価が高い」といった性格が生まれます。

5つの業態(スタンダード / テイクアウト特化 / 大型ラウンジ / ドライブスルー / ロースタリー旗艦店)と
店舗ごとの価格戦略(低価格/標準/高価格)で、**どの客層を取りに行くか**を選べます。

### 🏦 資金調達を「格付け＋融資契約」に作り直し
資産に連動して毎日ふらつく借入枠を廃止し、**信用格付け(D〜AAA)**と**個別の融資契約**にしました。

| 商品 | 内容 |
|---|---|
| ⚡ 短期運転資金 | 180日・高金利・審査が緩い。急場をしのぐ |
| 📈 事業拡大ローン | 730日・BB以上。標準的な設備資金 |
| 🏦 シンジケートローン | 1095日・A以上＋担保。大型で低利 |
| 📜 社債の発行 | 3年後に一括償還。上場かつBBB以上 |
| 💠 VC出資 | 未上場のみ。株式12%と引き換えに資金 |

契約ごとに金利・期間・日割り返済額が決まり、返済が滞ると格付けが落ち、続けば清算されます。

### 🚨 買収を「TOB(株式公開買付)という事件」へ
時間経過でファンドが買い進める仕組みを廃止。**持株が50%を切ったうえで**、赤字・割安・
低格付けなどの条件が重なると「買収の標的にされやすさ」が上がり、限界を超えると
**TOBが宣言されて30日の攻防**が始まります。

防衛策は6種(大規模自社株買い / ホワイトナイト要請 / ポイズンピル / 特別配当 / 緊急IR / 資産売却)で、
それぞれ賛同率を下げますが費用や副作用があります。期限までに株主の賛同率を50%未満に抑えれば撃退、
超えれば買収されてゲームオーバーです。**持株が過半数ならそもそも仕掛けられません。**

### ⚖️ 選択を迫る危機イベント
保健所の指摘・SNS炎上・店長の引き抜き・豆の高騰・法人契約の打診などで**ゲームが止まり、3択**を迫られます。
「衛生問題を伏せて営業を続ける」を選ぶと、後日発覚して壊滅的な打撃を受けることも。

### 🔬 経営研究と 🌆 第2都市
POSシステム・モバイルオーダー・サブスク・セルフレジ・研修センター・サプライチェーン改革・
ブランド戦略室・需要予測AIの8種を、日数をかけて1つずつ開発します(永続効果)。
第1都市の25枠が埋まったら、5億円で**第2都市(4地区・16枠)**へ進出できます。

### 🌸 四季と年間行事
春夏秋冬でホット/アイスの需要と人出が変わり、正月・バレンタイン・GW・夏休み・
ハロウィン・クリスマスに特需が発生します。

## 🛠️ ビルド方法

Android SDK は不要です。Java (JDK 11+) と curl があればビルドできます:

```bash
./build.sh
# => dist/CoffeeEmpire-debug.apk
```

スクリプトが以下を自動ダウンロードして使います:

| ツール | 役割 |
|---|---|
| [apktool](https://github.com/iBotPeaches/Apktool) | AndroidManifest/リソースのコンパイルと APK パッケージング |
| [dalvik-dx](https://mvnrepository.com/artifact/com.jakewharton.android.repackaged/dalvik-dx) | `.class` → `classes.dex` 変換 |
| [uber-apk-signer](https://github.com/patrickfav/uber-apk-signer) | zipalign + v1/v2/v3 署名 (デバッグ鍵) |
| android (stub jar) | `javac` 用のコンパイル時クラスパス |

## 📁 構成

```
coffee-empire-android/
├── src/MainActivity.java        # WebView をフルスクリーン表示するだけの薄いガワ
├── app/
│   ├── AndroidManifest.xml      # minSdk 21 / targetSdk 29
│   ├── apktool.yml
│   ├── res/                     # アプリ名・アイコン
│   └── assets/www/index.html    # ゲーム本体 (単一HTML・vanilla JS・依存なし)
├── build.sh                     # ビルドスクリプト
└── dist/CoffeeEmpire-debug.apk  # ビルド済みAPK
```

ゲームロジックはすべて `app/assets/www/index.html` にあり、PC のブラウザで直接開いてもプレイできます。
