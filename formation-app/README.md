# フォーメーションメーカー（Formation Maker）

ダンスの立ち位置・隊形（フォーメーション）を作成できる、完全無料のAndroidアプリです。
ArrangeUs のような隊形作成を、広告なし・課金なし・オフラインで行えます。

> ⚠️ 本アプリは ArrangeUs（ArrangeUs LLC）とは無関係のオリジナルアプリです。
> 既存アプリのコピーではなく、同じ用途のための独自実装です。

## インストール方法

1. GitHub Actions の「Build Formation Maker APK」を実行すると、
   `release/FormationMaker.apk` がこのリポジトリに追加されます
2. Android端末で APK をダウンロードして開く
3. 「提供元不明のアプリ」の許可を求められたら許可する
   （設定 → セキュリティ → 不明なアプリのインストール）
4. インストール完了。オフラインで動作し、権限は一切要求しません

## 主な機能

| 機能 | 説明 |
|---|---|
| 隊形エディタ | ダンサーをドラッグして立ち位置を配置。グリッド吸着（0.5m単位）対応 |
| 複数の隊形 | 曲の場面ごとに隊形を追加・複製・並べ替え・削除 |
| アニメーション再生 | 隊形間の移動をBPM×カウント数に合わせて再生 |
| 移動の見える化 | 前の隊形をうすく表示し、移動を矢印で表示（ゴースト機能） |
| メンバー管理 | 名前・色の設定、まとめて5人追加、複数選択して一括移動 |
| 整列ツール | 横一列・縦一列・円形・V字・2列に一発整列 |
| メモ | 各隊形に注意点などのメモを記録 |
| 自動保存 | 編集内容は端末に自動保存。複数作品の管理も可能 |
| 共有 | JSONファイルの書き出し/読み込みで他端末・友達とデータ交換 |
| 画像出力 | 全隊形の一覧表をPNG画像として保存（印刷・LINE共有に便利） |
| 元に戻す | 60ステップまでのアンドゥ/リドゥ |

## 使い方

### 基本操作
- **ダンサー（丸）をドラッグ** して立ち位置を決める
- 空きスペースをドラッグで画面移動、**2本指でピンチズーム**
- 右側の **⤢** で全体表示に戻る

### 隊形を作る
1. 画面下の **＋** を押すと、今の隊形をコピーして次の隊形が追加される
2. ダンサーを動かして次の立ち位置を作る
3. 下のチップ（隊形1、隊形2…）タップで切り替え。**同じチップをもう一度タップ**すると
   名前・カウント数・メモの編集、並べ替え、削除ができる
4. **▶** で通し再生。テンポは「⊞ → BPM」、移動の速さは各隊形の「カウント数」で調整

### データの保存・共有
- 編集は**自動保存**（アプリを閉じても消えません）
- ☰メニュー → 「データを書き出し」でJSONファイル保存 → 友達に送って
  「データを読み込み」で開いてもらえば共有完了

## 開発者向け：ビルド方法

```bash
cd formation-app
# Android SDK と Gradle 8.7 が必要
gradle assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

GitHub Actions（`.github/workflows/build-apk.yml`）を `workflow_dispatch` で実行すると
自動でビルドされ、APKが `release/` にコミットされます。

### 構成
- `app/src/main/assets/index.html` — アプリ本体（HTML5 Canvas製エディタ、依存ライブラリなし）
- `app/src/main/java/.../MainActivity.java` — WebViewラッパー
  （ファイル保存・読み込み・共有のブリッジのみ、権限不要）
- `signing/formation.keystore` — 個人利用向けの自己署名キー。
  **ストアで公開する場合は必ず自分のキーに差し替えてください**（このキーは公開リポジトリにあるため）
